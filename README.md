# Discover Ilocos Norte - Promotional Website

A beautiful, responsive promotional website for Ilocos Norte, Philippines. This website showcases the province's attractions, culture, local cuisine, and tourism services.

## 🌊 Website Features

### Pages Included:
1. **Home/Cover** - Eye-catching hero section with call-to-action buttons
2. **About Ilocos Norte** - Introduction to the destination
3. **Top Destinations** - Featured places (Bangui Windmills, Pagudpud, Paoay Church, Kapurpurawan)
4. **Experiences/Things to Do** - Six activity categories
5. **Local Food & Products** - Traditional Ilocano cuisine and souvenirs
6. **Tourism Services** - Accommodation, transportation, tours, dining
7. **Sample Tour Package** - 3 Days/2 Nights itinerary
8. **Promotional Ad** - Full-screen campaign section
9. **Travel Information** - What to prepare and travel tips
10. **Contact** - Contact information and call-to-action

## 🎨 Design Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- **Modern UI** - Clean, professional aesthetic with smooth animations
- **Color Scheme** - Earth tones reflecting Ilocos heritage:

  - Secondary: #2C5F2D (Forest Green)
  - Accent: #E8A76F (Light Brown)
- **High-Quality Images** - Beautiful photos from Unsplash
- **Smooth Scrolling** - Easy navigation between sections
- **Interactive Elements** - Hover effects, animations, and transitions
- **SEO Optimized** - Proper meta tags and semantic HTML
